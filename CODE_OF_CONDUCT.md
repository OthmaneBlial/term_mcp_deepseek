# Code of conduct

Term MCP DeepSeek should be a focused, safe place to discuss local developer tooling and security.

## Expected behavior

- Be respectful, direct, and specific.
- Critique code and ideas, not people.
- Assume good intent while still asking for evidence.
- Welcome beginners and explain project-specific constraints.
- Protect private data: redact tokens, paths, output, and personal information.
- Respect responsible disclosure and move vulnerabilities to private reporting.

## Unacceptable behavior

Harassment, discrimination, threats, doxxing, sexualized conduct, deliberate disruption, publishing private information, or pressuring someone to run unsafe commands is not accepted in project spaces.

## Enforcement

Report conduct concerns privately to the repository owner through the contact method on the owner’s GitHub profile. Include links or screenshots when safe. Reports will be reviewed confidentially and proportionately.

Maintainers may edit or remove content, restrict participation, or ban accounts when behavior threatens people, project safety, or constructive collaboration. Good-faith security research following [SECURITY.md](SECURITY.md) is welcome.

This policy applies to repository discussions, issues, pull requests, releases, and project-related public interactions.
